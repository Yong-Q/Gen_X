# Gen_X 科研文档的参考模式与采用方案

审阅日期：2026-10-22。以下项目依据实际文档和 notebook 内容筛选，链接固定到审阅提交。借鉴的是解释、组织和核验方式；各项目的结果不构成 Gen_X 的成果或精度证明。

## 1. 先区分文档要回答的问题

| 文档角色 | 读者需要得到什么 | Gen_X 对应页面 |
|---|---|---|
| 科学解释 | 为什么研究、目标分布是什么、公式在何种条件下成立、什么证据会推翻假设 | [研究方案](research_program.md)、[生成理论](generative_theory.md) |
| 教程 | 在明确前置条件下，完成一次范围有限且可验证的操作 | [使用教程](tutorial.md)；明确合成冒烟与真实模型推理的区别 |
| 操作指南 | 已知道目标时，完成复跑、环境准备或特定任务 | [水冰课题入口](../projects/water_ice_bgmat/README.md)、[真实生成记录](real_generation_results.md)的复跑部分 |
| 参考与证据 | 查询参数、单位、模型来源、文件含义及实际运行记录 | [势模型与环境](potentials_and_environment.md)、运行配置、模型元数据、日志与结果清单 |
| 仓库导航 | 选择课题、找到上述页面和结果 | [根 README](../README.md)，保持简短，不承担完整论文式论证 |

科学解释应先建立因果和假设，再给命令入口。教程可以成功运行，却仍未证明目标分布正确；参数参考完整，也不能替代研究意义和数学推导。

## 3. 把公式、训练、采样与物理验证接起来

| 链条位置 | 文档要求 | 页面与证据落点 |
|---|---|---|
| 科学目标→目标分布 | 先说明研究缺口、比较对象、主要性质及停止条件；玻璃显式包含势、初态和制备协议 | 研究方案第 1—5 节；生成理论第 1 节；[非晶课题入口](../projects/amorphous_generation/README.md) |
| 分布→变量与空间 | 定义坐标、元素、晶胞、条件、单位、概率测度、周期约束与对称性；说明简化欧氏推导何时适用 | 生成理论第 1、2、6 节；技术路线的数据约定；实际配置及模型元数据 |
| 数学模型→损失 | 从换元、ELBO 或概率路径给出推导，写清训练输入、目标、权重及期望所取分布；分别说明势训练与生成器训练 | 生成理论第 2—5 节；尚未执行的损失标为方法方案，不能暗示已用于本地训练 |
| 损失→采样算法 | 分开画训练与推理：训练读取参考样本并更新参数，采样从先验出发、调用冻结网络、迭代更新后输出构型 | 生成理论与[技术路线](technical_roadmap.md)；实际推理版本、配置和产物见真实生成记录 |
| 采样→物理验收 | 保留裸生成、拒绝样本与后处理结果；评价局部/中程结构、独立性质及成本，说明参考集合与评价势是否独立 | 研究方案的对照和留出设计、生成理论第 8—9 节；完成后将运行证据写入结果页 |
| 验收→反馈 | 生成器分布缺口与势能模型适用域误差分别触发补样/更新；回归用开发集，最终测试不参与调参 | 技术路线的两条回环、研究方案第 8 节；不能用同一模型的低能评分完成自我证明 |

每个主要公式之后应紧接变量表、成立条件、推导关键步、算法用途和失效情形。独立图注说明图中哪些是现有实现、哪些是拟议方法；推导图展示数学关系，工程图展示实际数据和文件流向，避免混用。

物理溯源最少记录：材料表示和自由度、组成/尺寸、势与权重来源及哈希、单位与应力符号、参考电子结构设置、制备/采样协议、数据划分、模型提交、随机种子、后处理预算和独立评价来源。缺项明确标为未核验。现有 mW 单珠水冰运行不能证明全原子水、非晶 SiO₂ 或跨参考势迁移成功。

## 4. 已安装的流程图技能及使用边界

项目内已安装 `markdown-mermaid-writing`，来源为 [K-Dense-AI/scientific-agent-skills 的固定目录](https://github.com/K-Dense-AI/scientific-agent-skills/tree/593377bb048752abb0152deab9fbb1083a6087df/skills/markdown-mermaid-writing)，提交为 `593377bb048752abb0152deab9fbb1083a6087df`。入口是 `.agents/skills/markdown-mermaid-writing/SKILL.md`；参考文件和模板应与入口一同保留。

优先用于总体路线、训练/采样分支、验收决策和两条反馈回环。写作不需要凭证或外部 API；需要导出图片时才使用本地渲染器。该版本的参考环境为 Mermaid CLI 12.0.0、Node.js 22.13+ 和 Chromium，实际环境及 HTML/PDF 导出仍需核验。保留可编辑源、矢量输出与图注，在最终页面尺寸检查文字、箭头、裁切和物理含义。定量数据图继续由可追溯的数据与绘图代码生成。

该 skill 含 Apache-2.0 的上游指南与模板，库级封装说明为 MIT，保留原有署名和许可说明。其提及的 `scientific-schematics` 是另一个可选工具，依赖付费 OpenRouter 图像/审图 API，且产生栅格图；此次流程图工作不依赖该服务。

## 5. 本轮文档验收

- 研究方案独立回答科学意义、可证伪假设、基线、数据预算与停止标准。
- 理论页贯通目标分布、推导、损失、采样与独立验证，不将能量最小化等同于系综正确。
- 流程图与正文相邻；参考势、标签和评价的来源清楚，训练和推理分支清楚。
- 结果页只陈述已运行事实，提供版本及日志；计划、教学示例与科学结果分别标注。
- README 保持导航职责；HTML/PDF 从文档源构建，交叉引用、图注和状态与源文件一致。
