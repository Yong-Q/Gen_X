## 最小目标

用作者公开的`params-mw_cubic_216.pkl`，在200 K、数密度0.033567184 Å⁻³下采样8个216粒子的mW立方冰构型。mW一粒子代表一水分子，不含显式氢。不训练势、不训练生成器、不使用GPU。

4. 验证形状、有限数值、周期盒、最小距离、样本差异和权重归一性；统计仅作小样本诊断，不据此声明论文分布精度已复现。
